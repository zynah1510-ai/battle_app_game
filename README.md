# ⚔️ Creature Battle Game (Streamlit)

A simple interactive turn-based battle game built using **Python** and **Streamlit**.

## 🐉 Features

- Choose your creature: Dragon or Goat
- Turn-based battle system
- Different attack moves for each creature
- Computer-controlled opponent (random attacks)
- HP system for both player and enemy
- Win/Lose detection
- Restart game option
- Simple UI with images

---

## 🎮 How to Play

1. Select your creature (Dragon or Goat)
2. Choose an attack move from dropdown
3. Click **Attack**
4. Enemy attacks automatically
5. First to reach 0 HP loses

---

## 🛠️ Tech Stack

- Python
- Streamlit
- Random module
